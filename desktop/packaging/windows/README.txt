Lumivane for Windows

1. Unzip this folder anywhere you like (not inside a protected folder such as Program Files).
2. Double-click Lumivane.exe.

Windows SmartScreen may say the app is from an unknown publisher, because the file is not code-signed.
Choose "More info", then "Run anyway". Verify the download with the SHA-256 shown on the release page first.

Settings and the bridge key are stored in %APPDATA%\Lumivane. The bridge key is encrypted for your Windows account.
To uninstall, delete this folder and %APPDATA%\Lumivane.
